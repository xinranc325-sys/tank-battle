# 坦克大战 - Tank Battle Game

一个使用纯HTML、CSS和JavaScript开发的经典坦克大战游戏。

## 游戏特性

- 🎮 经典的坦克大战玩法
- 🚀 流畅的游戏体验
- 🎯 智能敌人AI
- 🏆 分数系统和生命值
- 🎨 现代化的界面设计
- 📱 响应式布局

## 操作说明

- **方向键** - 控制坦克移动和转向
- **空格键** - 发射子弹
- **P键** - 暂停/继续游戏

## 游戏玩法

1. 点击"开始游戏"按钮启动游戏
2. 使用方向键移动坦克
3. 按空格键射击敌方坦克
4. 躲避敌方子弹和坦克
5. 击毁敌人获得分数
6. 生命值耗尽游戏结束
